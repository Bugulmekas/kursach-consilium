# Чек-лист: от «сырого» docx до защиты

Короткая версия. Подробности — в [инструкции](01-INSTRUCTION.md).

## Перед началом

- [ ] Есть копия исходного файла.
- [ ] Word открывает документ без диалога восстановления.
- [ ] Известны требования методички (объём, структура, оформление, библиография).
- [ ] Есть эталон рамок и штампов.

## Диагностика

- [ ] Посчитаны страницы, секции, таблицы, рисунки.
- [ ] Проверено, где полный штамп, где полоса, где штампа нет.
- [ ] Найдены дубли заголовков и старые фрагменты.
- [ ] Проверено, все ли источники цитируются.

## Консилиум

- [ ] Два независимых вердикта (методист, предметник).
- [ ] Не более 6–8 замечаний на каждого.
- [ ] Каждое замечание привязано к разделу.
- [ ] Разногласия сведены в протокол.
- [ ] По каждому разногласию есть решение и обоснование.

## Правки

- [ ] Текст и структура — до вёрстки.
- [ ] Команды и таблицы — после текста.
- [ ] Библиография — последней.
- [ ] Ничего не вставлено «на глаз»: все команды проверены по синтаксису.
- [ ] Дубли удалены, а не закомментированы.

## Вёрстка

- [ ] Титул — без штампа.
- [ ] СОДЕРЖАНИЕ — по требованию кафедры (полный штамп или без него).
- [ ] С 3-й страницы — нижняя полоса «Лист N».
- [ ] Приложение — в своей секции, полоса наследуется.
- [ ] Реквизиты и ФИО — чёрные.
- [ ] Текст не налезает на штампы.
- [ ] Поля и рамка не конфликтуют.

## Библиография

- [ ] Столько источников, сколько требует методичка.
- [ ] Каждый цитируется.
- [ ] Нет дублей.
- [ ] ГОСТ Р 7.0.100-2018.
- [ ] Нет недоступных доменов.
- [ ] Нет старых диапазонов ссылок.

## QA

- [ ] QA-проверки пройдены (нет FAIL).
- [ ] Оглавление обновлено дважды.
- [ ] Поля обновлены.
- [ ] Страницы пересчитаны.
- [ ] Файл сохранён и открывается заново.
- [ ] Скриншоты контрольных страниц сняты.

## Защита

- [ ] Задачи из введения соотнесены с выводами и заключением.
- [ ] Есть ответы на вопросы о границах применимости (что не проверялось, какие допущения).
- [ ] Команды, не выполненные на стенде, названы «рекомендуемой последовательностью».
- [ ] Ограничения названы честно.
