# QA-гейты: что проверять и что делать при провале

## 1. Автоматическая проверка

Скрипт: `scripts/consilium/qa_docx.py`.

```powershell
python -X utf8 scripts\consilium\qa_docx.py thesis.docx --sources 20 --require-stamp
```

| Проверка | Провал/WARN означает | Что делать |
|---|---|---|
| Счётчик страниц | `app.xml` без `<Pages>` | сохранить документ в Word |
| Секции | секций нет | проверить структуру docx |
| Заглушки | остались `TODO`, «Ваша тема» и т. п. | заменить на реальный текст |
| Ссылки `[n]` | есть нецитируемые или номера вне диапазона | сверить текст и список |
| Дубли заголовков | возможен дубль (или это оглавление) | проверить вручную |
| Подписи таблиц | таблиц больше, чем подписей | добавить «Таблица N – …» |
| Подписи рисунков | рисунков больше, чем подписей | добавить «Рисунок N – …» |
| Красный текст | остались красные run'ы | привести к чёрному |
| Поля штампа | нет `PAGE`/`NUMPAGES` | проверить колонтитулы |
| Обязательные фразы | нет нужного элемента | добавить |
| Запрещённые фразы | остался старый фрагмент | удалить |

Все проверки настраиваются через JSON:

```json
{
  "sources": 20,
  "require": ["ПРИЛОЖЕНИЕ А"],
  "forbid": ["TODO", "старая формулировка"],
  "placeholders": ["TODO", "Ваша тема", "???"],
  "require_stamp": true
}
```

## 2. Проверки, которые скрипт не делает

### Структура

- [ ] Оглавление совпадает с фактическими страницами.
- [ ] Нет пустых страниц.
- [ ] Приложение начинается с новой страницы.
- [ ] Нумерация сквозная.
- [ ] Задачи из введения соотнесены с выводами.

### Штампы

- [ ] Титул — без штампа.
- [ ] Содержание — по требованию кафедры.
- [ ] С 3-й — полоса «Лист N».
- [ ] «Листов» считается по `NUMPAGES`.
- [ ] Реквизиты и ФИО — чёрные.
- [ ] Текст не налезает на штамп.

### Содержание

- [ ] Команды синтаксически корректны.
- [ ] Конфиги согласованы между разделами (адрес, порт, путь, сокет).
- [ ] Ограничения названы.
- [ ] Нет выдуманных результатов.

### Файл

- [ ] Открывается без диалога восстановления.
- [ ] Размер не уменьшился подозрительно.
- [ ] После сохранения страницы не изменились.
- [ ] Есть резервная копия.

## 3. Правило возврата

Любой FAIL:

1. Не править «на глаз».
2. Найти точное место через `word_live_find_text` или XML.
3. Внести правку.
4. Повторить QA.
5. Только после отсутствия FAIL — финализация.
